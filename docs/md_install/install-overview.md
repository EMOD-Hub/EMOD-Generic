# Install

Epidemiological MODeling software (EMOD) can be installed on computers running Windows (Windows 10, Windows Server 12, and Windows HPC Server 12 (64-bit)) or Linux (CentOS 7.1). For either operating
system, there are relatively few prerequisites required and the EMOD executable (Eradication.exe) or Eradication binary for Linux is
pre-built from the latest EMOD source code release. After completing installation, you can run
simulations locally or on an HPC cluster using real-world data.

!!! note

        If you want to download and modify the EMOD source code and build the Eradication.exe or Eradication binary for Linux
        yourself, see [dev-install-overview](dev-install-overview.md).
